Support

고객 지원

두나를 사용하면서 궁금한 점이나 문제가 있다면 아래 내용을 확인해 주세요.

자주 묻는 질문

내 가계부 데이터는 어디에 저장되나요?

수입, 지출, 예산, 카테고리와 계좌 데이터는 기본적으로 사용자의 기기에 저장됩니다. 두나가 이 데이터를 광고에 사용하거나 판매하지 않습니다.

기기를 바꾸기 전에 무엇을 해야 하나요?

설정의 백업 기능으로 두나 백업 파일을 내보내 안전한 위치에 보관해 주세요. 새 기기에서 해당 파일을 선택해 복원할 수 있습니다.

문제 분석 데이터를 보내면 무엇이 전송되나요?

사용자가 앱 안에서 명시적으로 동의해 전송한 경우에만, 설정된 사용자 이름과 현재 가계부 데이터베이스 파일이 문제 진단을 위해 전송됩니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.

문의하기

일반적인 오류 제보와 기능 문의는 아래 공개 이슈 페이지를 이용할 수 있습니다. 공개 글에는 실제 금융 기록이나 개인정보를 첨부하지 마세요.

GitHub 지원 이슈 열기

개인정보 열람·삭제 요청 또는 비공개 문의: devGChobo@gmail.com

삭제 요청 제목에는 “두나 데이터 삭제 요청”을 적고, 앱에 설정한 이름(있는 경우), 문제 진단 데이터 전송을 실행한 대략적인 날짜와 시간, 삭제할 데이터 범위만 알려 주세요. 계좌번호, 거래 내역 또는 데이터베이스 파일은 이메일에 첨부하지 마세요.

English

Doona Support

Income, expense, budget, category, and account data is stored on your device by default. Export a Doona backup before moving to a new device.

If you explicitly choose to send diagnostic data in the app, your configured user name and current finance database files are uploaded solely for troubleshooting. See the Privacy Policy for details.

For general questions, use GitHub Issues. Do not post private financial records or personal information in a public issue.

Private or privacy-related requests: devGChobo@gmail.com

For a deletion request, use “Doona Data Deletion Request” as the subject and include only the name configured in the app, if any, the approximate date and time you sent diagnostic data, and the scope of data to delete. Do not attach account numbers, transaction records, or database files.
