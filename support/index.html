두나를 사용하면서 궁금한 점이나 문제가 있다면 아래 내용을 확인해 주세요.

자주 묻는 질문

내 가계부 데이터는 어디에 저장되나요?

수입, 지출, 예산, 카테고리와 계좌 데이터는 기본적으로 사용자의 기기에 저장됩니다. iCloud 동기화를 켜면 개인 iCloud 공간에 동기화됩니다. 계정에 로그인해 클라우드 백업을 직접 실행하거나, 문의할 때 진단 데이터 첨부를 선택하면 해당 데이터가 별도로 전송됩니다.

기기를 바꾸기 전에 무엇을 해야 하나요?

설정의 백업 기능으로 두나 백업 파일을 내보내 안전한 위치에 보관해 주세요. 로그인 후 클라우드 백업을 직접 실행할 수도 있습니다. 새 기기에서는 저장한 파일이나 해당 계정의 클라우드 백업을 복원할 수 있습니다. iCloud 동기화와 클라우드 백업은 서로 다른 기능입니다.

문의하면 내 가계부도 자동으로 전송되나요?

아니요. 일반 문의에는 작성한 제목·내용과 앱 버전, 기기, 운영체제, 언어·지역 정보가 포함되며 GitHub의 공개 지원 글로 등록됩니다. 진단 데이터 첨부를 직접 선택한 경우에만 가계부 데이터베이스와 보조 파일이 비공개로 전송됩니다. 진단 파일에는 실제 금융 기록이 포함될 수 있으므로 첨부 여부를 확인해 주세요.

이미 보낸 진단 데이터를 지울 수 있나요?

아래 메일로 삭제를 요청할 수 있습니다. 문의 글 주소와 글의 ‘진단 데이터’ 항목에 있는 참조 ID, 전송한 대략적인 날짜와 시간을 알려 주세요. 문의 등록에 실패해 글 주소나 참조 ID가 없다면 전송 시각과 앱 버전·기기를 알려 주세요. 자료를 특정하기 어려운 경우 추가 확인을 요청할 수 있습니다.

계정을 삭제하면 기기의 기록도 지워지나요?

계정 삭제는 설정의 계정 메뉴에서 진행할 수 있으며, 해당 계정의 클라우드 백업도 삭제 대상입니다. 기기 안의 기록, 내보낸 백업 파일, 개인 iCloud 데이터, 공개 문의 글과 별도로 전송한 진단 데이터는 계정 삭제와 구분됩니다. 필요한 자료를 먼저 백업하고 각 저장 위치에서 관리해 주세요.

광고는 어떤 화면에 나오나요?

앱 유지보수를 위해 통계 화면의 작은 배너와 수동 클라우드 백업 과정의 전면 광고가 표시될 수 있습니다. 광고는 비개인맞춤 방식으로 요청하며, 가계부 내역을 광고 선택에 사용하지 않습니다. 광고와 데이터 처리에 관한 자세한 내용은 개인정보처리방침을 확인해 주세요.

문의하기

일반적인 오류 제보와 기능 문의는 앱의 문의 기능이나 GitHub 지원 이슈를 이용해 주세요. 문의 글은 공개되므로 실제 금융 기록, 이메일, 계좌번호 등의 개인정보를 적거나 첨부하지 마세요.

비공개 문의 및 전송한 진단 데이터·계정 관련 열람·삭제 문의: devGChobo@gmail.com

진단 데이터 삭제 요청 제목은 ‘두나 진단 데이터 삭제 요청’으로 적고, 문의 글 주소·참조 ID·전송 시각·삭제할 범위만 알려 주세요. 참조 ID는 자료를 찾는 데 사용하며 본인 확인을 대신하지 않습니다. 계정 관련 문의에는 로그인에 사용한 이메일을 비공개 메일로 알려 주세요. 비밀번호, 인증 코드, 계좌번호, 거래 내역 또는 데이터베이스 파일은 보내지 마세요.

기기 안에만 저장된 기록은 운영자가 원격으로 열람하거나 삭제할 수 없습니다. 사용자가 앱에서 직접 관리할 수 있습니다. 진단 파일 삭제와 공개 문의 글 삭제는 별개이므로 글 삭제도 원하시면 함께 알려 주세요.

Doona Support

Where is my finance data stored?

Your records are stored on your device by default. Enabling iCloud sync synchronizes them with your private iCloud space. Data is separately uploaded when you sign in and manually run a cloud backup, or explicitly attach diagnostic data to a support request.

Before moving to a new device

Export a backup file to a safe location or sign in and manually create a cloud backup. On your new device, restore the file or the backup associated with that account. iCloud sync and account-based cloud backup are separate features.

Does a support request automatically upload my ledger?

No. A standard request posts your title, message, app version, device, operating system, and language/region to public GitHub Issues. Only if you explicitly select diagnostic attachments are your finance database and companion files uploaded privately. These files may contain actual financial records.

Deleting diagnostic data or an account

To request diagnostic deletion, email the issue URL, the reference ID shown in its Diagnostic Data section, the approximate upload time, and the scope of deletion. If submission failed and you have no URL or reference ID, provide the approximate time, app version, and device. Additional verification may be needed. A public reference ID helps locate an upload; it does not establish ownership.

You can delete your app account in Settings > Account; its cloud backup is also subject to deletion. This is separate from on-device records, exported files, private iCloud data, public support posts, and diagnostic attachments. Back up anything you need first and manage each storage location separately.

Advertising

A small Statistics banner and an interstitial during manual cloud backup may support app maintenance. Ads are requested as non-personalized ads; ledger records are not used to select ads. See the Privacy Policy.

Contact

Use the in-app support feature or GitHub Issues for general questions. Posts are public: do not include financial records or personal information.

Private inquiries and access/deletion requests for diagnostic data or accounts: devGChobo@gmail.com

Use ‘Doona Diagnostic Data Deletion Request’ as the subject and include the issue URL, reference ID, approximate upload time, and scope. For account inquiries, provide your sign-in email privately. Do not send passwords, verification codes, account numbers, transaction records, or database files.

The operator cannot remotely access or delete records kept only on your device. Deleting diagnostic files does not delete the public issue; mention that separately if needed.
